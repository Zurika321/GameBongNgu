I. CÁC MỤC ĐÃ VIẾT VÀO MÃ NGUỒN

[A1] Web: GroupBlock trong bảng phải
- Thêm 2 tab Properties / GroupBlock, giữ Properties trước đó.
- Tạo / sửa tên / xóa Group; tạo / sửa tên / xóa Variant.
- Chọn Group từ dropdown, chọn Variant hoặc None từ dropdown; danh sách Block theo ID.
- Kéo Block từ Skeleton thả vào Variant; có nút thêm Block đang chọn và xóa liên kết ID.
- Thao tác xóa liên kết không xóa Block thật khỏi Skeleton.
- Cho phép Weapon và Outfit hoạt động độc lập; None (chuỗi rỗng) chỉ ẩn Block gắn với Group đó.
- Group được áp dụng làm lớp lọc cuối: block.visible + Block Keyframe + hướng + GroupBlock.
- Đồng bộ hiển thị trên canvas, danh sách Skeleton và sprite sheet.
- Tích hợp với cơ chế Undo snapshot hiện có.

[A2] Một Bone có nhiều Block
- Xóa logic cũ gây mất Block cùng Bone trong attachBlockToBone() và createBlockFromImage().
- Không giới hạn một Bone chỉ có một component. ID riêng, transform riêng và ảnh riêng của Block được giữ.

[A3] Lưu / mở project web và Unity JSON
- Dự án web chứa trường model.groupBlocks; vẫn đọc được project cũ không có trường này.
- Lưu theo schema:
 groupBlocks: [
 {tên: "Vũ khí", mặc địnhBiến thể: "Kiếm", biến thể: [
 {tên: "Sword", blockIds: [101, 102]},
 {tên: "Dagger", blockIds: [103]}
 ]}
 ]
- defaultVariant = "" nghĩa là None.
- Unity export vẫn dùng format BoneAnimatorUnity, schemaVersion 1; thêm trường groupBlocks tùy chọn.
- Dữ liệu directions.blocks vẫn chứa TẤT CẢ Block (kể cả bộ đang ẩn); assets vẫn nhúng đủ ảnh dưới dạng dataUrl/Base64.
- Block cùng boneId không bị gộp thành một instance.
- Tên group/variant là dữ liệu, không hard-code tên Weapon/Outfit trong runtime.
- Unity C# đọc JSON cũ không có groupBlocks mà không yêu cầu nâng schemaVersion.

[A4] Tải ảnh / Sprite Sheet
- Hộp Quản lý ảnh thêm lựa chọn tải một PNG, tải ảnh của variant hiện tại, hoặc tải tất cả variant một Group.
- Khi tải theo Group, tạo một ZIP có các PNG tách thư mục theo Group, thứ tự Variant và tên ảnh.
- Sprite Sheet thêm chọn bộ hiện tại hoặc tất cả Variant thuộc một Group.
- Khi chọn tất cả Variant: xuất một ZIP chứa từng Sprite Sheet riêng, có thể thêm Manifest JSON.
- Với nhiều Group: chỉ lặp các Variant của Group do người dùng chọn, các Group khác giữ lựa chọn hiện tại.
 KHÔNG sinh mọi tổ hợp giữa Weapon x Outfit; tránh bùng nổ file.
- Thay đổi biến thể tạm thời để render không sửa defaultVariant đang chỉnh trong editor.
- ZIP được tạo bằng JavaScript thuần (STORE + CRC32), không thêm thư viện ngoài.

[A5] Nhân vật Unity Hoạt hình / Trình chỉnh sửa
- Bổ sung DTO UnityGroupBlockData/UnityGroupVariantData và field serialized groupSelections.
- Validate Group và Variant trùng tên, ID Block không tồn tại, hoặc ID bị gán vào nhiều biến thể/group.
- Thêm API công cộng:
 bool SetGroupVariant(stringgroupName, string variantName)
 string GetGroupVariant(string groupName)
 void RefreshGroupVariantVisibility()
- Runtime đổi SpriteRenderer.enabled sau khi xét Block Keyframe + hướng + GroupBlock.
- Thay Variant không reset currentFrame, elapsed, animation, hướng hoặc skillId.
- Tạo cache theo blockId để không quét toàn bộ Group mỗi frame.
- Inspector tạo dropdown lấy từ JSON theo tên Group và tên Variant; có lựa chọn None.
- Lưu tùy chọn bằng SerializedProperty, hỗ trợ Undo.RecordObject + EditorUtility.SetDirty.
- Khi vào Play Mode, lựa chọn serialized được giữ và áp dụng trước khi dựng rig.
- Không đổi AnimState, luồng PlayAnimationSkill/BeginSkillCast, SFX, registry hoặc SaveData.

 bool SetGroupVariant(stringgroupName, string variantName)
 Tên API cuối cùng có thể theo quy ước dự án; phải có ví dụ gọi dễ hiểu.
