Quy tắc cho AI

1. Khi yêu cầu xóa 1 object hay canva gì đó trong scene tuyệt đối ko tạo script kiểm tra cái đó còn không và tắt mà phải vào file .unity mà xóa
2. Cấm viết các code cứng vd: tạo 1 gameobject hay UI trong game khi bật game lên
3. Khi yêu cầu thiết lập ui hay gameobject trong game thì phải thêm trong file .unity tuyệt đối ko dùng code kiểm tra có chưa rồi tạo
4. Được phép tạo các asset để admin kéo thả những thứ còn thiếu vào làm cho code mở rộng được không phải code cứng
5. Khi sửa file .unity tuyệt đối chỉ thêm không xóa trừ trường hợp t kêu xóa (xác định chích xác cái t kêu xóa không xóa nguyên cái cha bao quanh nó), nếu xóa cái mà t ko nói bạn bị vi phạm quy tắc nghiêm trọng
